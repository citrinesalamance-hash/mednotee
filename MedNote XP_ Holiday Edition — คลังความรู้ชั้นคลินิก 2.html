PDF เป็นขนาด A4 มีเลขหน้า แต่ละโน้ตขึ้นหน้าใหม่ · ตัวหนังสือในไฟล์เป็นภาพ จึงเลือกคัดลอก/ค้นหาในไฟล์ไม่ได้ ถ้าต้องการข้อความจริงให้กด “พิมพ์แทน” แล้วเลือก “บันทึกเป็น PDF”
🔗ซิงก์ผ่าน GitHub
หน้านี้เปิดผ่าน claude.ai จึงใช้ระบบซิงก์ของ claude.ai อยู่แล้ว การเชื่อม GitHub ใช้ได้เฉพาะเมื่อเปิดไฟล์จากเว็บของคุณเอง (เช่น GitHub Pages)
  1. สร้าง repo ใหม่ใน GitHub แบบ Private และติ๊ก “Add a README file”
  2. ไปที่ Settings > Developer settings > Fine-grained tokens > สร้าง token ใหม่ เลือก Only select repositories เฉพาะ repo นั้น และตั้ง Contents: Read and write
  3. ใส่ชื่อ repo กับ token ด้านล่าง แล้วกด “เชื่อมต่อ” (ทำซ้ำบนเครื่องอื่นด้วยค่าเดียวกัน)
token เก็บในเบราว์เซอร์เครื่องนี้เท่านั้น ใครใช้เครื่องนี้ได้ก็ใช้ token ได้ จึงควรจำกัดสิทธิ์ไว้ที่ repo เดียว และอย่าใส่ข้อมูลระบุตัวผู้ป่วยในโน้ต
